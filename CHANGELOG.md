- `audits/2026-06-14-terra-legal-stabilization.md` — repository stabilization audit.

### Changed

- Replaced the conflicting root `LICENSE` with a scoped multi-license notice.
- Replaced the former default `LICENSE.md` Terra Public License text with a stabilized repository License Policy.
- Updated `CITATION.cff` to remove CC0 metadata and align the citable repository material with CC BY 4.0.
- Updated README and Living Index to expose the stabilized legal, responsible-use, trademark, third-party, and draft-license layers.
- Expanded README, Living Index, standards, documentary layer, donor registry, glossary, validation, audit, repository, publication, and template protocol surfaces.
- Extended the reusable repository README template with naming, identity, TraceLog, and continuity sections.
- Added the portfolio licensing map, legal framework strategy, and relicensing protocol to the public reading path.

### Known issues

- File-level SPDX headers and full dependency review remain pending.
- Some legacy `.terra-legal` links remain to be normalized.
- Several repositories outside `terra-legal` still contain Terra Public License copies, damaged copies, incomplete stubs, or obsolete pointers.
- Contributor, ownership, dependency, publisher, media, and item-level corpus rights audits remain pending for the wider portfolio.
- The active GitHub Pages `index.html` still uses the earlier embedded visual style.
- Multilingual companion files for the new donor surfaces remain pending.

### Planned

- File-level audit inside `terra-legal`.
- Repository-by-repository rights audit under `RELICENSING_PROTOCOL.md`.
- Separate operator decisions for each target license and ownership identity.
- Draft Contributor Policy, Data and Corpus Rights Policy, Publication Rights Policy, Privacy Notice template, and Commercial Licensing Policy.
- Verified normalization of legacy repository links.
- Public-page migration to the shared accessible stylesheet.
- Russian and Uzbek Latin companion surfaces for core new documents.
- Zenodo DOI registration after a verified release.
