# Technical Glossary

This file defines a compact donor glossary for recurring Terra, FMP, AIUZ, naming, identity, trace, and publication-facing technical terms.

## Purpose

The glossary exists so repositories do not keep redefining the same technical language from scratch.

It supports:

- readable public surfaces;
- stable cross-repository terminology;
- publication coherence;
- bibliography and citation repair;
- reduction of semantic drift;
- consistent naming and visual identity;
- continuity-preserving repository work.

## Core terms

### Codex

A norm-and-meaning layer that binds operational rules, trace discipline, and human-facing interpretation.

### Trace

The continuity layer that preserves provenance, session memory, repair history, and operational sequence.

### TraceLog

A role-limited public or protected record of documentary decisions, sources consulted, changes made, Detox passes, validation status, unresolved risks, and integrity references.

TraceLog is not hidden behavioral monitoring.

### Invisible Shadow

A continuity concept describing meaningful relations, context, and recovery paths that may remain active when formal records or explicit explanations are incomplete.

Inside `terra-legal`, it functions as an anti-fragmentation and anti-capture bridge, not as the complete theory corpus.

### Silent Archiving

Preservation of necessary continuity without compulsory public disclosure or unnecessary data collection.

### Contextual Bridge

A document that states not only that two surfaces are linked, but why the dependency exists and which meaning must be preserved.

### Resilience

The ability of a repository, workflow, or knowledge layer to survive noise, damage, and fragmentation without losing recoverability.

### Layer

A distinct functional stratum within a repository or ecosystem, such as theory, practice, governance, publication, identity, machine, or archive.

### Protocol

A declared operational sequence or rule set that governs how work, validation, trace, or publication proceeds.

### Governance

The decision and responsibility layer that governs permissions, obligations, roles, and escalation paths.

### Ontology

A structured meaning map defining entities, relations, roles, and conceptual boundaries.

### Standard

A repeatable rule for format, structure, naming, validation, identity, or publication quality.

### Naming Standard

A source-first rule set for assigning, reviewing, approving, changing, and deprecating ecosystem names without losing origin or role clarity.

### Name Card

A traceable record of one name's origin, meaning, language checks, aliases, review status, limitations, and operator decision.

### Brand Identity

The stable visual and rhetorical recognition layer shared by public Terra surfaces.

Brand identity must improve clarity and must not imply legal status, scientific proof, or operational capability that does not exist.

### Visual Identity Guide

A documented set of colors, typography, spacing, layout, diagram, and accessibility rules used to preserve recognition across surfaces.

### DID

Decentralized identifier logic used for identity representation and traceable agent or stakeholder roles.

### DAO role

A declared role within a governance structure, such as `user`, `operator`, `stakeholder`, `verifier`, or `arbiter`.

### Semantic Integrity

A validation condition requiring that a change preserve meaning coherence rather than only passing syntactic checks.

### Thesaurus

A semantic lexicon layer supporting multilingual term mapping, concept mapping, and contextual interpretation.

### Session Continuity

The operational memory connecting one working session to the next without forcing re-creation from zero.

### Multilingual Packaging Protocol

A rule that publication or repository artifacts be packaged across required language surfaces with explicit structure and traceability.

## Use rule

If a repository uses these terms publicly, it should either:

- link back to this glossary;
- inherit its definitions directly;
- or document deliberate local divergence.
