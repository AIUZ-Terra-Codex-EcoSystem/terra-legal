# Terra Naming Registry

This directory records public, internal, blocked, and deprecated names governed by `NAMING_STANDARD.md`.

## Registry rules

- one name or tightly bound name family per file;
- use lowercase repository-safe filenames;
- preserve former names and aliases;
- state whether legal review occurred;
- never present a draft name as approved;
- connect every material decision to `TRACELOG.md`.

## Status markers

- `proposed`;
- `under linguistic review`;
- `under legal review`;
- `accepted for internal use`;
- `accepted for public use`;
- `accepted with jurisdiction limits`;
- `deprecated`;
- `blocked`.

## Current cards

- [`terra-legal.md`](./terra-legal.md) — repository name and public role.

## Boundary

This registry documents semantic and documentary decisions. It is not a trademark register, legal opinion, or evidence of exclusive rights.
