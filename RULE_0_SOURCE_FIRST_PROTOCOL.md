# Rule 0 Source-First Protocol

This file extracts and bridges the documentary surfaces for Rule 0 and Rule 0.5 from the broader Terra and FMP corpus.

It is included in `terra-legal` because these rules govern how documentary, analytical, and repository work must begin before any new synthesis or modification.

## Rule 0 — Source-First (No blind invention)

Before producing new solutions, text, or structures:

1. Search existing ecosystem artifacts first:
   - monograph;
   - codex;
   - archives;
   - prior iterations;
   - donor repositories.
2. If an answer already exists, reuse and adapt it with traceable mapping rather than inventing a parallel rule.
3. Only if no relevant pattern exists, proceed with operator-guided synthesis.

### Constraint

No authority claims by the assistant.
Only traceable linkage to existing artifacts and operator decisions.

## Rule 0 as mandatory FMP search

In the FMP-specific layer, Rule 0 takes a stricter form:

1. Study the FMP monograph and existing theoretical base before proposing an answer.
2. Search the available FMP theory parts for a ready method, precedent, or pattern.
3. Extract usable methodology from the existing theory.
4. Only when the answer is not present in the FMP corpus, escalate to operator-guided synthesis.

### Prohibitions

- Do not create new solutions before searching the theory.
- Do not invent methodologies when ready ones already exist in FMP.
- Do not propose improvements without reading the theoretical base.

## Rule 0.5 — NULLO-First Principle

Before FMP search and analysis:

1. Engage NULLO as generative substrate.
2. Search for intuitive or pre-conceptual insight before formal artifact search.
3. Record NULLO-level preliminary patterns.
4. Only then proceed into explicit FMP corpus search and extraction.
