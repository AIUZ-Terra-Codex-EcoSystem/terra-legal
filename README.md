## Licensing

There is no single blanket license for every file.

- file-specific notices and `REUSE.toml` control;
- CC BY 4.0 and Apache-2.0 apply only to explicitly classified files;
- Terra Public License remains a draft;
- earlier public grants are not represented as revoked;
- unclassified historical files remain pending rights review.

## Important limits

This repository is not the whole Terra or FMP corpus and is not proof of certification, partnership, scientific validation, professional legal review, or production security.

Current exclusions include historical file-level rights review, older third-party material, formal external deposit metadata, specialist deployment review, and controlling multilingual legal versions.
