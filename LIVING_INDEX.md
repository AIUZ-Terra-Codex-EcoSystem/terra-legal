## Current legal status

- no single blanket repository license;
- file-level licensing is controlling;
- CC BY 4.0 and Apache-2.0 apply only where a file is explicitly classified;
- Terra Public License is preserved as a draft rather than presented as an active repository license;
- historical grants are not represented as revoked;
- unclassified historical files remain pending file-level rights review;
- linked repositories do not inherit a license, certification, or official status automatically.

## Use rule

This index is living and reviewable.

It must remain traceable to donor documents, operator instructions, source evidence, and recorded protocol updates.

## Provenance rule

When a normative file is added or materially changed, record:

- donor source location;
- reason for inclusion;
- whether the file is literal donor text, extracted protocol surface, policy, legal scope notice, archived draft, or bridge document;
- applicable license and rights boundary;
- TraceLog relation;
- unresolved professional-review requirements.
